## 一、这是什么

三套**上下串联**的选股程序，运行顺序固定：

```
① MACD底背离筛选  →  ② 周线动力系统  →  ③ 价值区间选股
   （选形态）           （选动能）          （选位置）
```

前一层输出的 CSV，自动成为后一层的输入，**不需要手动指定路径**。

| 层 | 系统 | 作用 | 输出文件 |
|---|---|---|---|
| ① | MACD底背离筛选系统 | 找价格创新低但动能没创新低的股票 | `output/macd_divergence_YYYYMMDD.csv` |
| ② | 周线动力系统 | 在①的结果里，按周线动能筛红/蓝 | `output/power_color_YYYYMMDD.csv` |
| ③ | 价值区间选股系统 | 在②的结果里，按 EMA13/EMA26 位置筛 | `价值区间选股系统/output/value_zone_YYYYMMDD.csv` |

### ⚠️ 为什么不拆开发送

第②层代码里写死了：

```python
MACD底背离筛选系统/output/     # 找同级的 ① 的输出
```

第③层代码里写死了：

```python
../MACD底背离筛选系统/data/    # 找上一级目录的 ① 的缓存
../output/                     # 找上一级目录的 ② 的输出
```

**三个文件夹一旦分开，路径立刻断掉，程序会直接报"文件不存在"退出。**
所以必须整个 `A股股票筛选系统/` 文件夹一起拷贝/解压。

## 四、运行方式

在 `A股股票筛选系统/` 目录下，**按顺序**执行：

### 第①层：MACD底背离筛选

```bash
cd MACD底背离筛选系统
python main.py
```

- 数据源：新浪财经 `stock_zh_a_daily`（前复权日线，含成交量）
- 首次运行需拉取全市场约 5000 只股票，**耗时较长**（受网络影响，可能 1 小时以上）
- 数据落盘缓存到 `data/*.csv`，**之后每天运行只增量更新，很快**
- 支持断点续跑：中途中断后重新运行会自动跳过已处理的股票

### 第②层：周线动力系统

```bash
cd ..                          # 回到 A股股票筛选系统/
python power_filter_main.py
```

- 自动读取 ① 的最新结果，**无需传参**
- 如需指定其他输入：`python power_filter_main.py 某个CSV路径`
- 注意：本层**独立联网**重新拉日线数据，**不复用** ① 的缓存

### 第③层：价值区间选股

```bash
cd 价值区间选股系统
python value_zone_scanner.py
```

- 自动读取 ② 的最新结果，**无需传参**
- 本层**不联网**，全部读取 ① 的本地缓存 `MACD底背离筛选系统/data/`
- ⚠️ **前提：① 必须已经跑过并生成缓存**。若 `data/` 为空，本层会因找不到数据而返回空结果

## 五、三个策略的判定逻辑

### ① MACD底背离（`filters/macd_divergence.py`）

- 标准 MACD 参数：EMA12 / EMA26 / DEA9，`DIF = EMA12 − EMA26`
- **在价格最低价序列上**找波段低点（`lookback=20`、`min_gap=5`）
- 低点识别**无未来函数**：只向左看历史窗口，且需当日反弹确认，因此最后一个交易日不会被当作低点
- 判定"最近两个波谷"：
  1. 价格明显创新低：`Low2 < Low1 × 0.98`（至少低 2%）
  2. DIF 没创新低：`DIF2 > DIF1`
  3. 两低点间隔：`5 ≤ 距离 ≤ 60` 个交易日
- 三者同时满足即入选

### ② 周线动力系统（`filters/power_color_filter.py`）

- 日线 → 按周重采样（`W-FRI`，周收盘取该周最后一天，周成交量求和）
- 计算：`E13 = EMA(Close,13)`、`DIF = EMA(Close,12) − EMA(Close,26)`、`DEA = EMA(DIF,9)`、`HIST = DIF − DEA`
- 用**最近两周**比较：

| 颜色 | 条件 | 含义 |
|---|---|---|
| 🔴 红色 | E13 上升 **且** HIST 上升 | 多头动能增强 |
| 🔵 蓝色 | E13 上升且 HIST 下降，**或** E13 下降且 HIST 上升 | 分歧 / 调整 |
| 🟢 绿色 | E13 下降 **且** HIST 下降 | 空头动能增强（**不输出**，直接过滤） |

- 输出排序：红色在前，蓝色在后

### ③ 价值区间（`value_zone_scanner.py`）

- 出自《以交易为生》的 EMA 价值区间概念
- `上沿 = max(EMA13, EMA26)`，`下沿 = min(EMA13, EMA26)`
- 入选条件：`收盘价 ≤ 上沿`（即股价处于价值区间内或之下）
- 位置标注：
  - `价值区间内` → 收盘价 ≥ 下沿
  - `价值区间下` → 收盘价 < 下沿
- 输出排序：蓝色优先、价值区间内优先

### 全流程统一过滤

- 北交所（代码 43 / 83 / 87 / 92 开头）
- ST / *ST / 退市
- 上市不足 60 个交易日

## 七、常见问题

**Q：跑第②层提示找不到 MACD 输出文件？**
A：第①层还没跑过，或 `MACD底背离筛选系统/output/` 下没有 `macd_divergence_*.csv`。

**Q：第③层结果为空？**
A：多半是 `MACD底背离筛选系统/data/` 缓存为空 —— 先跑第①层。

**Q：脚本卡住不动？**
A：数据源为公开免费接口，网络不佳时会卡。代码已内置 20 秒 socket 超时 + 30 秒单只超时保护，连续失败会自动保存退出，重新运行即可续跑。

**Q：运行报 PermissionError？**
A：别用 Excel 打开 `output/` 里的 CSV，Windows 文件锁会导致写入失败。
