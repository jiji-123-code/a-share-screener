这个目录存放 A 股日线数据缓存（每只股票一个 CSV）。

【重要】该目录不包含在本 Git 仓库中（体积约 1.3 GB）。

获取缓存的方式（二选一）：

方式一：自己运行生成（推荐）
    在本目录的上一级（MACD底背离筛选系统/）下执行：
        python main.py
    程序会自动拉取全市场日线并写入本目录。首次约需 1 小时（受网络影响），
    之后每天运行只做增量更新，几秒即可完成。

方式二：从 GitHub Release 附件下载
    在本仓库的 Releases 页面下载 data 压缩包，解压后把 CSV 文件全部放入本目录。

【为什么需要它】
    第①层 MACD底背离筛选 会写入缓存；
    第③层 价值区间选股 需要读取本目录的缓存（该层不联网）。
    若本目录为空，第③层会因找不到数据而返回空结果。

缓存文件格式：date, open, high, low, close, volume（前复权，每只 120+ 根K线）
